## Design Context

### Users
**Primary audience:** ML engineers, data scientists, technical recruiters, and senior engineers evaluating AutoML tooling.
**Context of use:** Local laptop / cloud deployment. Users upload a CSV, watch intelligent analysis happen in real-time, and receive a deployable trained model package.
**Job to be done:** "I want to train the best possible model on my dataset without spending hours on hyperparameter grid searches — I want the system to be smarter than me."
**Secondary audience:** Judges, interviewers, and technical evaluators who need to understand — within 30 seconds of looking — that something genuinely intelligent is happening under the hood.

### Brand Personality
**3-word personality:** Cinematic · Surgical · Inevitable
**Voice:** The interface speaks in ALL CAPS, short commands, telemetry readouts. It's a mission control operator, not a SaaS product. Every label is a directive.
**Emotional goals:** Users should feel like they're operating a supercomputer. Calm confidence, not urgency. Precision, not busyness.

### Aesthetic Direction
**Visual tone:** Cyberpunk-adjacent biopunk HUD. "Neural Mission Control" — not gaming, not generic dark mode. References: NASA telemetry panels, DNA sequencer readouts, 90s-era supercomputer terminals.
**Established tokens (LOCKED — do not change):**
```
--void: #03040A        /* deepest background */
--deep: #080B14        /* sidebar background */
--surface: #0D1220
--panel: #111827
--border: #1a2540
--dna-green: #00FF88   /* primary accent — life/success */
--neural-amber: #FFB800 /* secondary — processing/warning */
--quantum-magenta: #FF006E /* CTA / high-stakes */
--bio-cyan: #00D4FF    /* data / information */
--evolution-purple: #9B5DE5 /* advanced/elite */
--font-display: 'Bebas Neue' — headers, large numbers
--font-tech: 'Chakra Petch' — body, labels
--font-mono: 'Share Tech Mono' — code, telemetry readouts
```
**Anti-references:** Generic SaaS (rounded cards, soft gradients, modal-first patterns), gaming UIs (too aggressive), Grafana dashboards (too utilitarian).
**Theme:** Dark mode only. Light mode is never appropriate for this tool.

### Design Principles

1. **The UI is an instrument panel, not a form.** Every element should communicate system intelligence — live charts, phase indicators, telemetry. Static forms are the enemy.

2. **Angularity over roundness.** `clip-path: polygon(0 0, calc(100% - 10px) 0, 100% 10px, 100% 100%, 0 100%)` is the MetaTune chamfer motif. Apply it wherever possible. `border-radius: 0` everywhere except pill shapes and orbital spinners.

3. **Tokens over hardcodes, always.** Every color MUST come from a CSS variable. No `#FF4B4B`, no `#1A0A0A`, no `rgba(0,0,0,0.8)` — use token equivalents.

4. **Motion must mean something.** Animations communicate state (orbital spin = processing, heartbeat = idle/alive, matrixFlicker = active computation, glitchText = unstable/exciting). Never animate for decoration alone. Respect `prefers-reduced-motion`.

5. **Typography serves hierarchy.** `font-display` (Bebas Neue) = major headings and large metrics only. `font-mono` (Share Tech Mono) = labels, readouts, status text. `font-tech` (Chakra Petch) = body and secondary information.

## Known UI Issues (from /audit)

### P0 — Critical
- [ ] **Error card breaks design system**: Training failure divs use `border-radius: 10px` and hardcoded `#FF4B4B44` / `#1A0A0A` instead of design tokens and chamfer motif
- [ ] **PyTorch branch `payload` undefined**: `payload` variable is only set in the sklearn branch; the PyTorch download button references it but it may be undefined

### P1 — High
- [ ] **Missing `fonts.gstatic.com` preconnect**: Google Fonts loads slower without preconnect hint
- [ ] **`box-shadow` animations trigger repaints**: `ignitePulse`, `neuralPulse` animate `box-shadow` — should use `filter: drop-shadow()` on a transformed element for GPU-composited path
- [ ] **5-column metric grid overflows on small screens**: `grid-template-columns: repeat(5, 1fr)` in live training header has no responsive fallback
- [ ] **Double divider**: `---` + custom HTML border-top creates duplicate separator before PHASE 03

### P2 — Medium
- [ ] **Missing `prefers-reduced-motion`**: All animations run regardless of system accessibility setting
- [ ] **No ARIA labels on status indicators**: Colored dots with no text alternative for screen readers
- [ ] **Missing empty state after training error**: No reset affordance shown when training fails
- [ ] **`label_visibility="collapsed"` on algorithm selectbox**: Hides label entirely — should use visually-hidden pattern instead

### P3 — Low
- [ ] **Hero HTML duplication**: `HERO_HTML_ORIGINAL` and `HERO_HTML_CENTERED` share 90% identical code — extract shared parts
- [ ] **`time.sleep(0.02)` in training loop**: Adds ~600ms of unnecessary delay over 30 epochs
- [ ] **Hardcoded `height=800`** on `components.html` intro — should be `window.innerHeight`
